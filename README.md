## Ejecución y Funcionalidades

### Paso 1 - Iniciar la aplicación web

- Abrir una nueva terminal en el mismo directorio raíz (TP2_HCI_G4).
- Ejecutar los siguientes comandos:

```
cd smarthome-hci 
npm install
npm run preview
```

Al ejecutar el último comando, se abrirá automáticamente la página local de SmartHome, donde podrá visualizar 
y navegar por la aplicación.
